# FairPrice — передаточный документ

Состояние проекта на 2026-11-09. Этот файл — источник истины, если контекст сессии потерян.

## Что это

Android-приложение, которое показывает цену за килограмм/литр поверх карточек товаров в приложениях магазинов. Работает через AccessibilityService: читает дерево экрана, считает ₽/кг и рисует чип.

- Пакет: `ru.vlad.unitprice`
- Репозиторий: https://github.com/VasiVlad/FairPrice
- Текущая версия: **0.21** (versionCode 21)
- Ключ подписи: `unitprice/debug.keystore` (не в git, беречь)

## Стек и сборка

Java, без AndroidX и Gradle. Сборка вручную:

- `%LOCALAPPDATA%\AndroidDev\jdk` — JDK 17
- `%LOCALAPPDATA%\AndroidDev\sdk` — Android SDK, build-tools 33.0.2
- `build-manual.ps1` — aapt2 → javac → d8 → jar → zipalign → apksigner

Порядок выпуска:

1. Поднять версию в `build-manual.ps1` (`--version-code`, `--version-name`) и в `app/build.gradle.kts`.
2. `powershell -ExecutionPolicy Bypass -File build-manual.ps1`
3. `git add -A && git commit -m "vX.Y: ..." && git push`
4. Создать релиз через GitHub API, приложить APK.
   Токен: `git credential fill` (protocol=https, host=github.com).

Установка на устройство:

```
adb -s <dev> install -r --user 0 <apk>
```

Если `INSTALL_FAILED_VERIFICATION_FAILURE`:

```
adb shell settings put global verifier_verify_adb_installs 0
adb shell settings put global package_verifier_enable 0
```

## Архитектура

- `UnitPriceService` — AccessibilityService: события, дебаунс, скролл/удержание, сторожевой пересчёт, screen-off, systemui.
- `CardBuilder` — из текстовых узлов собирает карточки: цена, вес, фото/контейнер, дедуп.
- `TextParser` — форматы цен и весов.
- `OverlayManager` — чипы `TYPE_ACCESSIBILITY_OVERLAY`, видимость, позиционирование, пропуск неизменной отрисовки.
- `MainActivity` — статус службы, переключатели, проверка обновлений, вход в тест.
- `TestActivity` — полигон парсера с эталонными значениями.
- `UpdateChecker` / `UpdateInstaller` / `InstallResultReceiver` — обновление изнутри через GitHub Releases и PackageInstaller.
- `OverlayTileService` — плитка в шторке.
- `Prefs` — настройки и список пакетов.

## Правила парсера (важно не сломать)

- `isPriceNode`: в строке есть цена и нет букв, кроме допустимого хвоста `/шт`, `/кг`, `/л`.
- `parsePrice`: берётся **последняя** цена в строке (Бристоль: `49.99 ₽ 44 99 ₽` → 44.99).
- Если цена явно `₽/кг` или `₽/л` — она используется напрямую, вес и остаток не ищутся (важно для товаров на развес).
- `SPACED_KOPECKS`: `104 99` → 104.99.
- Дедуп цен на карточке:
  - обе цены за штуку → берётся **меньшая** (актуальная/по карте);
  - если замешана цена за кг/л → по размеру шрифта;
  - одинаковая цена на большой карточке (dy 80–350) → остаётся нижняя.
- Товары без веса (салфетки, трусики, подгузники, пелёнки) не считаются.
- Комбинированная строка не может быть «названием с весом» для соседней карточки.
- Фото: «голая» картинка над ценой (центр ±220 px, зазор ≤650), иначе — минимальный контейнер, содержащий цену.
- Видимость: ≥90% по обеим осям, отсечение обрезки краем, отсечение карточек под липкой шапкой (в списках фото.top < 0.19H; если фото нет — цена.top < 0.18H).
- Удержание: 350 мс, скрытие; возврат при отпускании, аварийно через 2.5 с.
- Скролл: скрытие сразу, пересчёт через 120 мс после остановки.
- Сторожевой пересчёт: каждые 2.5 с.
- Экран блокировки: `SCREEN_OFF` и `systemui` очищают чипы.
- Пропуск отрисовки, если набор и координаты карточек не изменились.

## Известные хвосты

- Проверить на товарной странице ВкусВилла выбор цены по карте (должно быть 733 для кекса, не 813) после v0.21.
- Проверить «48 мл» салфетки после v0.17.
- Эвристики липкой шапки могут давать ложные пропуски на нестандартных экранах.
- История цен не реализована (обсуждается on-device SQLite).
- Камера/ценники — только обсуждение: сначала фото-режим, затем живой оверлей.

## Правила безопасности

- `debug.keystore` не терять: без него не встанут обновления поверх.
- Не автоматизировать оплату.
- Не собирать данные на сервер: сеть только для проверки/установки обновлений.
